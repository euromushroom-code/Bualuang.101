## ดาวเด่นบัวหลวง 101

เว็บไซต์ประชาสัมพันธ์โครงการ **ดาวเด่นบัวหลวง 101**
ออกแบบในสไตล์ **Modern · Professional · Gen Z** เน้นภาพลักษณ์ที่ทันสมัย ใช้งานง่าย และเหมาะกับการรับชมทั้งบนคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ

---

## ✦ Project

**Bualuang 101**
เว็บไซต์รวบรวมข้อมูลโครงการ กิจกรรม ผู้เข้าร่วม ข่าวสาร และกำหนดการสำคัญของโครงการไว้ในพื้นที่เดียว

เว็บไซต์เน้นการนำเสนอข้อมูลแบบ Visual-first เพื่อให้ผู้เข้าชมสามารถเข้าถึงข้อมูลสำคัญได้อย่างรวดเร็ว พร้อมดีไซน์ที่มีความเป็นวัยรุ่นและร่วมสมัยมากขึ้น

## ✦ Website Sections

เว็บไซต์ประกอบด้วยส่วนหลัก ได้แก่

* **HOME** — หน้าแรกและภาพรวมโครงการ
* **ABOUT** — ข้อมูลเกี่ยวกับโครงการ
* **SCHEDULE** — กำหนดการและ Timeline
* **ACTIVITIES** — กิจกรรมภายในโครงการ
* **PARTICIPANTS** — ข้อมูลผู้เข้าร่วม
* **NEWS** — ข่าวสารและประกาศ
* **GALLERY** — ภาพกิจกรรมและผลงาน
* **CONTACT** — ช่องทางการติดต่อ
